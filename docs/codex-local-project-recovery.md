# Codex 可见性修复中的项目与归属恢复

继续使用「会话管理 → 修复可见性」现有的快速修复、完整修复。账号、实例和 API 服务启动预览中的入口复用同一个弹框，并默认选中当前实例；没有单独的本地项目选项或切号提示。

## 快速修复

修正可见性索引，同时依据当前项目数据库和 JSON 补齐本地项目、新旧 ID 映射及会话归属，更新主线程和已有本地目录记录。项目补齐不读取历史快照、不扫描聊天正文、不探测项目目录，也不复制整个数据库。

项目补齐有独立的短时间预算和记录数限制。快速备份包含 JSON 和准确的字段变更计划，可按字段撤销；只处理有明确依据的记录。元数据过大、数据库忙、并发变化或实例仍在运行时，保留已有数据，在原结果或启动进度中说明维护推迟，可退出目标实例后重试或使用完整修复。预览不写入数据。

普通切号不增加项目扫描或完整恢复。“切号并启动”、默认实例和多开实例仍使用同一套后端启动事务及启动前快速修复，慢速维护不作为新的启动前置步骤。

## 完整修复

包含项目与归属补齐，并可结合有效目录和历史 JSON 快照恢复缺失信息；同时执行已有的 Provider/目录修复及会话索引修复。必须完全退出所选桌面实例后应用，仍可在运行时预览。原来的独立“修复会话索引”入口继续保留。

会话索引部分检查原始记录与祖先链，备份并清理已确认失效的派生索引，由客户端重建。历史文件较多时会较慢，因此这部分仅进入完整修复和独立索引修复，不进入快速修复或自动启动。

## 数据边界与恢复

- 支持 macOS 路径和 Windows 盘符、UNC、长路径前缀；项目 ID 不按路径处理，POSIX 路径保留大小写及反斜杠语义。
- 保留明确无项目的会话、较新的归属和删除记录；排除云项目、子 Agent、guardian 和无法唯一判断的归属。完整恢复会跳过不可用的项目目录。
- 不读取账号凭据文件，不修改账号、聊天正文、归档状态或聊天更新时间，不上传修复数据。Provider 的调整仍由原有可见性修复负责；项目恢复本身不改 Provider，也不提供跨账号云项目同步或加密历史转换。
- 完整项目恢复在宿主统一备份目录创建 JSON、相关 SQLite 一致性备份和 `project-recovery-plan.json`；快速恢复保留 JSON 与字段变更计划。结果返回实际备份目录。
- 写入前保存 `.cockpit-local-project-recovery.json` 中断标记。写入失败按计划撤销；进程中断后，退出目标实例并执行完整修复，会先恢复未完成写入。快速修复保留中断计划并推迟相关项目维护。
- 回滚只恢复仍等于本次写入结果的字段或记录，保留后来新增的聊天及较新归属，不用旧 SQLite 文件覆盖当前历史。各实例、Provider 修复、项目恢复和索引修复分阶段提交；后续阶段失败时，错误保留已完成阶段的备份信息，便于重试。
